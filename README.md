# Lily English

给 8 岁孩子的英文陪伴网页：听力、口语、阅读、单词。小猫咪 Coco 会朗读英文、鼓励跟读，进度存在这台设备上。

## 怎么给女儿用

1. 用 **Safari**（iPad / iPhone）或电脑浏览器打开 `index.html`。
2. iPad：点分享 → **添加到主屏幕**，之后就像 App。
3. 口语请允许麦克风。自动听写在部分 iPad 上不稳定，这时让她大声跟读，再点「我会了」。

本地预览需要一个小网站服务（直接双击文件时，朗读通常还能用，但「添加到主屏幕」需要网址）。装好开发工具后可以用：

```bash
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。

## 现在有什么

- **听力**：4 段稍长的小故事，句子里有 because、but、so，生日那篇用过去时
- **口语**：对话要说出原因或昨天做了什么，外加跟读和问答
- **阅读**：6 本分级小书，仍是一页一页翻；Level 3 用过去时讲完一件事
- **单词**：相近的长句里选出正确的一句，要分清 because、but、so
- **课本学习**：3A Unit 1–4 整页看单词和句子，点一行就听。默写在纸上写，听中文或听英文都可以，写完再看答案
- **课外学习**：《童话故事记完小学1000词》前 7 课，学单词和课文，默写同样写在纸上
- 星星和连续天数记在浏览器里
